# Spirit Realm Thai Mod (มอดภาษาไทย)

มอดแปลภาษาไทยแบบไม่เป็นทางการสำหรับเกม **Spirit Realm (灵境·修仙界)** บน Steam
(เกมเล่นคนเดียว, Unreal Engine 5.7) — โปรเจกต์นี้ไม่มีส่วนเกี่ยวข้องกับผู้พัฒนาเกม

## ดาวน์โหลด

ไปที่ [Releases](https://github.com/waylanders05/SpiritRealmThaiMod/releases) แล้วโหลดไฟล์ zip ของรุ่นล่าสุด (v2.4)

- **เฉพาะ build 25987949 เท่านั้น** — ตัวติดตั้งตรวจเวอร์ชันเกมให้อัตโนมัติ
  ถ้าเกมอัปเดตแล้วตัวติดตั้งปฏิเสธ ให้รอรุ่นใหม่ ห้ามใช้รุ่นเก่ากับเกมเวอร์ชันอื่น
- ใช้ v2.3 อยู่ → ติดตั้ง v2.4 ทับได้เลย ไม่ต้องถอนก่อน
- ใช้ v2.1/v2.2 → อัปเดตเกมผ่าน Steam แล้วถอนมอดเก่าด้วย Verify integrity ก่อน

## ขอบเขตการแปล (v2.4)

- ✅ เมนู/UI/ไอเทม/สกิล/เควสต์/หน้า patch notes ครบทุกข้อความที่เก็บได้จากไฟล์เกม
- ✅ **บทสนทนาเนื้อเรื่องเต็มจอ + ชื่อผู้พูด** (เพิ่มเข้าระบบ localization ของเกมเอง โดยไม่แตะโค้ดเกม)
- ✅ ชื่อ NPC (หยางซิว, อู่เวย ฯลฯ) ทั้งป้ายกด E และหัวบทสนทนา
- ✅ ฟอนต์ไทยครบทุกจุด รวม tooltip ที่เคยเป็น `?????`
- ✅ ศัพท์ขั้นบำเพ็ญสไตล์นิยาย (รวมรวมปราณ → สร้างรากฐาน → แก่นทองคำ → หยวนอิง → เทพจำแลง) และคำแปลผ่านการบุรณะด้วย AI 4 รอบ
- ❌ ชื่อ NPC สุ่ม/อุปนิสัย (ฝังใน .exe), ชื่อเควสต์บางรายการ (แปลแล้วเควสต์พัง), tooltip ◆ เหนือหัว NPC

## ติดตั้ง / ถอน

1. แตก zip แล้วดับเบิลคลิก **ติดตั้ง.bat** (ตัวติดตั้งสำรองไฟล์เดิมไว้ให้เสมอ)
2. ในเกม: ตั้งค่า > ภาษา > เลือก **繁體中文** (จะกลายเป็นภาษาไทย) แล้วรีสตาร์ทเกมหนึ่งครั้ง
3. ถอน: ดับเบิลคลิก **ถอนการติดตั้ง.bat** หรือ Steam Verify integrity

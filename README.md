# Spirit Realm Thai Mod (มอดภาษาไทย)

มอดแปลภาษาไทยแบบไม่เป็นทางการสำหรับเกม **Spirit Realm (灵境·修仙界)** บน Steam
(เกมเล่นคนเดียว, Unreal Engine 5.7) — โปรเจกต์นี้ไม่มีส่วนเกี่ยวข้องกับผู้พัฒนาเกม

## ดาวน์โหลด

ไปที่ [Releases](https://github.com/waylanders05/SpiritRealmThaiMod/releases) แล้วโหลดไฟล์ zip ของรุ่นล่าสุด

- **เฉพาะ build 25540193 (v0.7.4.6)** เท่านั้น — ตัวติดตั้งตรวจเวอร์ชันเกมให้อัตโนมัติ
  ถ้าเกมอัปเดตแล้วตัวติดตั้งปฏิเสธ ให้รอรุ่นใหม่ ห้ามใช้รุ่นเก่ากับเกมเวอร์ชันอื่น

## ติดตั้ง / ถอน

1. แตก zip แล้วดับเบิลคลิก **ติดตั้ง.bat** (ตัวติดตั้งสำรองไฟล์เดิมไว้ให้เสมอ)
2. ในเกม: ตั้งค่า > ภาษา > เลือก **繁體中文** (จะกลายเป็นภาษาไทย)
3. ถอน: ดับเบิลคลิก **ถอนการติดตั้ง.bat** หรือ Steam Verify integrity

## ขอบเขตการแปล

- ✅ เมนู/UI/ไอเทม/สกิล/เควสต์/หน้า patch notes + เนื้อหาทั้งหมดที่เก็บได้จากไฟล์เกม (~35,000 ข้อความ)
- ❌ บทสนทนาเนื้อเรื่องเต็มจอ, ชื่อ NPC (จงใจไม่แปลเพื่อกันระบบเควสต์พัง), tooltip ◆

## หมายเหตุ

- มอดแก้ไฟล์เกมโดยตรง — Steam Verify integrity คืนค่าเดิมได้ทุกเมื่อ
- ฟอนต์ไทย: Noto Sans Thai (SIL Open Font License)
